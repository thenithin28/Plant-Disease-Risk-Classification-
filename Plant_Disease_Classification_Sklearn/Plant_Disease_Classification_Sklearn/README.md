# Plant Disease Classification

A beginner-friendly machine learning project using Python and Scikit-learn to classify plant leaf conditions.

## Algorithm
Random Forest Classifier

## Features
- Leaf Color Score
- Leaf Spot Count
- Leaf Moisture
- Leaf Texture Score
- Plant Age
- Soil Moisture
- Temperature

## Classes
- Healthy
- Powdery Mildew
- Leaf Spot
- Rust

## Run
```bash
pip install -r requirements.txt
python train_model.py
python predict.py
streamlit run app.py
```

The dataset is synthetic and intended for academic/educational use only. This is not a real agricultural diagnosis system.
